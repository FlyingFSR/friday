# Maintainer field notes

Short notes from the maintainer's own daily use of Friday between releases.
These are one person's observations on one set of Macs, not compatibility or
accuracy claims. They live here rather than in [CHANGELOG.md](../CHANGELOG.md)
so the changelog stays a record of what shipped.

Newest first.

## 2026-06-20 — after 0.3.5

After several days of daily push-to-talk use on the Medium-only build (Turbo was
retired in 0.3.4), the maintainer has seen no recurrence of the intermittent
mid-sentence character drops that motivated retiring Turbo. Dictation has been
consistently reliable in normal use. As always, this is early maintainer
feedback rather than a broad accuracy claim, but it confirms that the decision to
ship Medium only is holding up well in practice.

## 2026-06-10 — after 0.3.1

After several days of real daily use on the current release, Friday has been
stable and handy for the maintainer's own push-to-talk workflow, with no
blocking issues observed during that period. This is still early maintainer
feedback rather than a broad compatibility claim, but it is a useful signal that
the 0.3.x reliability work is holding up in normal use.
